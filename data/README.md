Place the NASA C-MAPSS FD001 files in this folder:

- train_FD001.txt
- test_FD001.txt
- RUL_FD001.txt

Download the Turbofan Engine Degradation Simulation Data Set (C-MAPSS) from NASA's Prognostics Center of Excellence data repository:
https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/

The data files are intentionally not bundled in this starter project.
